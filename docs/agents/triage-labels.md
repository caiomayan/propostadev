# Triage Labels

As skills falam em cinco papéis canônicos de triagem. Este arquivo mapeia esses papéis para as strings usadas neste tracker. No tracker local, a string vai na linha `Status:` de cada issue.

| Label em mattpocock/skills | Label neste tracker | Significado                                   |
| -------------------------- | ------------------- | --------------------------------------------- |
| `needs-triage`             | `needs-triage`      | O dono precisa avaliar esta issue             |
| `needs-info`               | `needs-info`        | Aguardando mais informação de quem reportou   |
| `ready-for-agent`          | `ready-for-agent`   | Totalmente especificada, pronta para um agente |
| `ready-for-human`          | `ready-for-human`   | Exige implementação humana                    |
| `wontfix`                  | `wontfix`           | Não será feita                                |

Quando uma skill citar um papel (por exemplo, "aplicar o label AFK-ready"), use a string correspondente desta tabela.
